# PM Dekor szerkesztő v7.3

Ez a gyorsított verzió egyszerre hozza a három fontos módosítást:

## 1. Légiesebb blokkok
- a blokkok már kevésbé takarják a hátteret
- a külső blokkfelületek áttetszőbbek
- inkább a képek kapnak finom keretet, nem egy nagy tömör doboz

## 2. Klasszikus blokk-típusok
- minden blokknál választható:
  - **Klasszikus plakát**
  - **Szellős**
- a **Klasszikus plakát** nézet a minta logikáját követi:
  - közös árszalag
  - közös cím
  - képenként mini ár
  - képenként mini alcím

## 3. Tipográfia / spacing finomhangolás
- elegánsabb árszalag
- jobb blokkcím arányok
- finomabb sor- és blokkközök
- nyugodtabb fejléc / lábléc arányok

## Maradt
- sor- és blokkszerkesztő
- csonka sorok
- crop / újravágás
- intelligens képfeltöltés
- dinamikus logókezelés
